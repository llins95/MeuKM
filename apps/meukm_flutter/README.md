# MeuKM para Android e Windows

Beta Flutter do aplicativo nativo, criada para compartilhar o mesmo código entre Android e Windows.

## Executar

```bash
flutter pub get
flutter run
```

O projeto inclui navegação responsiva, cadastro de registros, cálculos de consumo e previsão, gráficos, exportação PNG/PDF, login e sincronização com a mesma conta do PWA. O fluxo do GitHub Actions analisa, testa e compila o APK e o pacote ZIP do Windows.
